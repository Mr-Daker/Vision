Reports by ward and category. A cell reading “No data” means nothing can be concluded about it, which is not the same as a cell reading zero. Each row adds up to its ward total, including the “Other categories” column.
How to read this table

0 means the summary is up to date and matches the records, and it found no reports here. No data means the summary is behind the records or has not been checked, so nothing can be concluded — it is not zero, and it is not evidence that there is nothing wrong there. The same empty slot is shown one way or the other depending on whether the summary above can be trusted. Select any count to open the reports behind it.

“Other categories” holds reports filed under a category this deployment does not track. They are counted so every row adds up to its ward total.
